数据库 Schema 定义

本文档定义了 footx-app 的核心数据库结构。所有表使用 PostgreSQL 16+，采用 UUID 主键和 TIMESTAMPTZ 时间戳。参见 PRD.md#数据模型 和 api-contract.md#数据类型。

迁移脚本遵循 migrations/README.md 规范（断链 — 文件尚未创建）。

用户表

存储所有注册用户信息。email 字段具有唯一约束，用于登录认证。

users public
iduuidPK
emailvarchar(255)NOT NULL
namevarchar(100)NOT NULL
avatar_urltext
roleuser_roleNOT NULL'customer'
created_attimestamptzNOT NULLnow()
updated_attimestamptzNOT NULLnow()

产品表

商品目录。price 以分为整数存储（避免浮点精度问题），通过 api-contract.md 的除以 100 转换为元。

products public
iduuidPK
namevarchar(200)NOT NULL
descriptiontext
price_centsintegerNOT NULL
stockintegerNOT NULL0
categoryproduct_categoryNOT NULL
activebooleanNOT NULLtrue
created_attimestamptzNOT NULLnow()

订单表

用户订单主表。status 字段使用 user_role 枚举类型追踪订单生命周期。

orders public
iduuidPK
user_iduuidFKNOT NULL
statusorder_statusNOT NULL'pending'
total_centsintegerNOT NULL
created_attimestamptzNOT NULLnow()
updated_attimestamptzNOT NULLnow()

订单项表

订单中的具体商品行项。每条记录关联一个订单和一个产品。

order_items public
iduuidPK
order_iduuidFKNOT NULL
product_iduuidFKNOT NULL
quantityintegerNOT NULL
unit_price_centsintegerNOT NULL
