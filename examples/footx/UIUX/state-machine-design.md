## 1. 状态机概述

### 1.1 设计原则

- **原子性**: 每个状态代表用户界面的一个确定视觉状态
- **完整性**: 涵盖正常流程和所有异常分支
- **可追溯性**: 每个状态转移都有明确的触发条件和事件
- **可恢复性**: 异常状态都有明确的恢复路径

### 1.2 状态分类

| 类别 | 说明 | 视觉标识 |
|------|------|---------|
| **初始态** | 用户旅程的起点 | 🟦 |
| **处理态** | 系统正在处理操作 | 🟨 |
| **等待态** | 等待外部输入或审核 | ⬜ |
| **成功态** | 操作完成成功 | 🟩 |
| **异常态** | 操作失败或需要重试 | 🟥 |
| **终态** | 流程结束 | ⬛ |

### 3.2 登录分支状态详解

| 当前状态 | 触发事件 | 目标状态 | 界面表现 | 恢复策略 |
|---------|---------|---------|---------|---------|
| `LOGGED_OUT` | 点击登录/注册按钮 | `AUTH_STARTING` | 显示登录弹窗 | - |
| `AUTH_STARTING` | 选择邮箱登录 | `CODE_SENDING` | 显示邮箱输入框 | 返回上一步 |
| `AUTH_STARTING` | 选择 Google 登录 | `VERIFYING` | 显示 OAuth 窗口 | 返回上一步 |
| `CODE_SENDING` | 发送成功 | `CODE_SENT` | 显示验证码输入框 | - |
| `CODE_SENDING` | 发送失败 | `CODE_SEND_FAIL` | 显示错误提示+重试按钮 | 点击重试 |
| `CODE_SENT` | 输入验证码 | `VERIFYING` | 显示加载中 | - |
| `VERIFYING` | 验证成功 | `REFERRAL_CHECK` | 显示加载中 | - |
| `VERIFYING` | 验证码错误 | `VERIFY_FAIL` | 显示错误提示 | 重新输入 |
| `VERIFYING` | 验证码过期 | `VERIFY_FAIL` | 提示过期+重新发送 | 重新发送 |
| `REFERRAL_CHECK` | 有邀请码 | `REWARD_APPLY` | 显示奖励发放中 | - |
| `REFERRAL_CHECK` | 无邀请码 | `LOGGED_IN` | 跳转原页面 | - |
| `REWARD_APPLY` | 奖励发放成功 | `LOGGED_IN` | 显示奖励到账提示 | - |
| `REWARD_APPLY` | 奖励发放失败 | `LOGGED_IN` | 静默失败，正常登录 | 后台重试 |

### 4.2 视频采集异常分支详解

#### 4.2.1 摄像头权限被拒绝

```
状态转移: CAMERA_INIT → PERM_DENIED

触发条件:
- 用户点击"拒绝"摄像头权限
- 浏览器自动阻止摄像头访问
- 设备无可用摄像头

界面表现:
┌────────────────────────────────────────┐
│  ⚠️ 无法访问摄像头                      │
│                                        │
│  我们需要摄像头权限来拍摄您的足部视频    │
│                                        │
│  [前往设置授权]  [使用本地视频上传]      │
│                                        │
│  💡 提示：您也可以上传已拍摄好的视频文件 │
└────────────────────────────────────────┘

恢复路径:
1. PERM_DENIED --点击"前往设置"--> 浏览器权限设置
2. PERM_DENIED --点击"本地上传"--> FILE_SELECT
3. PERM_DENIED --浏览器返回授权--> CAMERA_INIT
```

#### 4.2.2 本地文件上传分支

```
状态转移: PERM_DENIED → FILE_SELECT → FILE_VALIDATING → UPLOADING

文件验证规则:
┌─────────────────────────────────────────────────────────────┐
│ 验证项          │ 要求              │ 失败处理               │
├─────────────────────────────────────────────────────────────┤
│ 文件格式        │ MP4, MOV, AVI     │ 提示格式不支持          │
│ 文件大小        │ ≤500MB            │ 提示文件过大+压缩建议    │
│ 视频时长        │ 10-30秒           │ 提示时长不符            │
│ 视频分辨率      │ ≥720p             │ 警告可能影响分析精度     │
│ 视频方向        │ 横屏/竖屏均可      │ 提示调整拍摄方向         │
└─────────────────────────────────────────────────────────────┘

文件验证失败状态:
- FILE_FORMAT_ERR: 格式不支持，显示支持格式列表
- FILE_SIZE_ERR: 文件过大，提供压缩工具建议
- FILE_DURATION_ERR: 时长不符，提示重新录制
```

#### 4.2.3 上传失败处理

```
状态转移: UPLOADING → UPLOAD_FAIL

失败类型及处理:
┌─────────────────────────────────────────────────────────────┐
│ 失败类型        │ 重试策略              │ 用户提示           │
├─────────────────────────────────────────────────────────────┤
│ 网络中断        │ 断点续传              │ "网络不稳定，正在恢复" │
│ 服务器错误      │ 指数退避重试(3次)      │ "服务器繁忙，请稍候"   │
│ 存储空间不足    │ 不可重试              │ "请联系客服"         │
│ 文件损坏        │ 提示重新选择          │ "文件损坏，请重新选择" │
└─────────────────────────────────────────────────────────────┘

断点续传机制:
UPLOAD_FAIL(网络中断) --恢复网络--> UPLOADING(断点续传)
                              ↓
                         显示进度: "已上传 45%，继续上传..."
```

#### 4.2.4 视频审核结果通知

```
审核状态机:

REVIEW_WAIT (等待审核)
    │
    ├── 审核通过 ──→ REVIEW_PASS ──→ 自动进入建模流程
    │
    └── 审核不通过 ──→ REVIEW_FAIL
              │
              ├── 光线不足 ──→ 提示："请在光线充足的环境重新拍摄"
              │
              ├── 角度不对 ──→ 提示："请按照示例角度拍摄，确保足部清晰可见"
              │
              ├── 画面模糊 ──→ 提示："画面不够清晰，请保持稳定拍摄"
              │
              └── 时长不足 ──→ 提示："视频时长不足，请拍摄完整的行走过程"
              │
              └── 所有情况 ──→ [重新拍摄] 按钮，返回 RECORDING
```

### 4.4 支付失败分支详解

| 失败类型 | Stripe 错误码 | 用户提示 | 建议操作 |
|---------|--------------|---------|---------|
| 银行卡被拒绝 | `card_declined` | "您的银行卡被拒绝，请联系发卡行或更换支付方式" | 提供更换支付方式选项 |
| 余额不足 | `insufficient_funds` | "银行卡余额不足，请更换支付方式" | 提示余额不足，建议换卡 |
| 过期卡片 | `expired_card` | "您的银行卡已过期，请更换有效卡片" | 引导更新卡片信息 |
| 错误CVV | `incorrect_cvc` | "安全码(CVV)错误，请检查后重新输入" | 提示重新输入CVV |

### 4.5 订单超时机制

```
订单创建后启动 15 分钟倒计时:

ORDER_CREATED
    │
    ├── 15分钟内支付成功 ──→ PAY_SUCCESS
    │
    └── 15分钟未支付 ──→ ORDER_EXPIRED
              │
              ├── 自动取消订单
              ├── 释放优惠券
              ├── 发送"订单已取消"邮件
              └── 界面显示: "订单已过期，请重新下单"

倒计时提醒:
- 剩余 5 分钟: 显示警告 "订单即将过期，请尽快完成支付"
- 剩余 1 分钟: 显示紧急警告 "订单将在1分钟后过期"
```

## 10. 状态机实现建议

### 10.1 前端状态管理架构

```typescript
// 使用 XState 或自定义状态机
// 推荐：使用 XState 实现复杂状态机

import { createMachine, interpret } from 'xstate';

const videoCaptureMachine = createMachine({
  id: 'videoCapture',
  initial: 'idle',
  states: {
    idle: {
      on: { START: 'guide' }
    },
    guide: {
      on: {
        NEXT: 'cameraInit',
        SKIP: 'cameraInit'
      }
    },
    cameraInit: {
      on: {
        PERMISSION_GRANTED: 'cameraReady',
        PERMISSION_DENIED: 'permissionDenied',
        USE_UPLOAD: 'fileSelect'
      }
    },
    permissionDenied: {
      on: {
        RETRY: 'cameraInit',
        USE_UPLOAD: 'fileSelect'
      }
    },
    cameraReady: {
      on: {
        START_RECORD: 'recording',
        USE_UPLOAD: 'fileSelect'
      }
    },
    recording: {
      on: {
        STOP: 'recordDone',
        TIMEOUT: 'recordDone'
      }
    },
    recordDone: {
      on: {
        PREVIEW: 'preview',
        RETAKE: 'cameraReady',
        UPLOAD: 'uploading'
      }
    },
    preview: {
      on: {
        ACCEPT: 'uploading',
        RETAKE: 'cameraReady'
      }
    },
    fileSelect: {
      on: {
        FILE_SELECTED: 'fileValidating',
        CANCEL: 'cameraInit'
      }
    },
    fileValidating: {
      on: {
        VALID: 'uploading',
        INVALID: 'fileInvalid'
      }
    },
    fileInvalid: {
      on: {
        RETRY: 'fileSelect'
      }
    },
    uploading: {
      on: {
        PROGRESS: { actions: 'updateProgress' },
        SUCCESS: 'uploadSuccess',
        FAIL: 'uploadFail',
        CANCEL: 'cameraReady'
      }
    },
    uploadFail: {
      on: {
        RETRY: 'uploading',
        USE_FILE: 'fileSelect',
        BACK: 'recordDone'
      }
    },
    uploadSuccess: {
      type: 'final'
    }
  }
});

// 使用状态机
const service = interpret(videoCaptureMachine)
  .onTransition((state) => {
    console.log('Current state:', state.value);
    // 更新 UI
    updateUI(state);
  })
  .start();
```

### 10.2 状态持久化

```typescript
// 关键状态需要持久化，防止页面刷新丢失

interface PersistentState {
  // 订单草稿
  orderDraft: {
    productId: string;
    videoUrl: string | null;
    formData: Partial<FormData>;
    addressId: string | null;
    couponId: string | null;
  };

  // 视频录制进度（断点续传）
  uploadProgress: {
    fileId: string;
    uploadedBytes: number;
    totalBytes: number;
  };

  // 支付会话
  paymentSession: {
    orderId: string;
    stripeSessionId: string;
    expiresAt: number;
  };
}

// 使用 localStorage + 时间戳
const persistState = (state: PersistentState) => {
  localStorage.setItem('footx_state', JSON.stringify({
    ...state,
    timestamp: Date.now()
  }));
};

// 恢复时检查过期
const restoreState = (): PersistentState | null => {
  const saved = localStorage.getItem('footx_state');
  if (!saved) return null;

  const parsed = JSON.parse(saved);
  // 支付会话15分钟过期
  if (parsed.paymentSession && Date.now() > parsed.paymentSession.expiresAt) {
    parsed.paymentSession = null;
  }
  return parsed;
};
```
