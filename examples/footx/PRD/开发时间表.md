## AI Agent 使用策略

### 高效使用 AI 的建议

| 场景 | 使用方法 |
|------|---------|
| **代码生成** | 提供清晰的上下文（PRD + 数据结构设计），让 AI 生成完整模块 |
| **组件开发** | 提供设计稿或详细描述，让 AI 生成 React/Vue 组件 |
| **API 开发** | 提供数据库 schema，让 AI 生成 CRUD API |
| **Bug 修复** | 提供错误信息和相关代码，让 AI 分析原因 |
| **代码审查** | 让 AI 审查生成的代码，找出潜在问题 |

### 注意事项

1. **不要完全依赖 AI**：复杂业务逻辑（如优惠券发放、邀请关系）需要人工 review
2. **保持代码规范**：让 AI 遵循统一的代码风格
3. **预留联调时间**：AI 生成的模块之间可能需要人工联调
4. **版本控制**：频繁提交，方便回滚

## 风险与应对

| 风险 | 可能性 | 应对策略 |
|------|--------|----------|
| 视频采集兼容性问题 | 中 | 第 3 周重点测试移动端，准备上传备选方案 |
| Stripe 集成复杂 | 中 | 提前阅读 Stripe 文档，先用测试模式跑通 |
| 邀请逻辑 bug | 中 | 第 5 周预留时间专门测试边界情况 |
| 性能不达标 | 低 | 第 7 周专门优化，必要时加缓存 |
| 个人精力不足 | 中 | 每周留 1 天缓冲，避免连续高强度工作 |

## 总结

- **8 周时间足够**完成 Foot X V1.0，前提是合理使用 AI Agent
