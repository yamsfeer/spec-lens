## 文档概览

本文档站点包含 Foot X 项目的完整技术文档，按模块组织如下：

- **user-flow.md** - 用户流程图，展示核心功能的用户操作路径

- **edge-functions.md** - Edge Functions 架构设计
- **deployment-solution.md** - 部署方案详细说明

### 📄 contract - 契约与规范

- **api-contract.md** - RESTful API 接口契约，前后端交互规范
